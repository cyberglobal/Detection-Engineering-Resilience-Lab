# Detection-Engineering-Resilience-Lab

A Windows and Splunk SOC lab focused on brute-force detection and detection reliability.

## Project Overview

This project:
- investigates Windows failed logons
- builds and tunes a brute-force detection in Splunk
- maps the detection to MITRE ATT&CK T1110
- creates a Sigma equivalent
- tests whether the logging pipeline is healthy
- checks whether required detection fields are still present
